## 개요

본 문서는 GPON OLT 장비에서 발생하는 가입자 인증 실패 오류의 원인과 조치 방법을 기술한다.

문서 번호: TS-OLT-0142
작성자: 액세스망운용팀

## E-411 인증 실패

E-411은 ONT 시리얼 번호가 OLT 가입자 DB에 등록되지 않았을 때 발생한다.
펌웨어 3.2 이상에서는 자동 등록이 기본 비활성화되어 있어 수동 등록이 필요하다.

조치 절차는 다음과 같다.
1. OLT CLI에서 show ont autofind 명령으로 미등록 ONT 시리얼을 확인한다.
2. ont add 명령으로 해당 시리얼을 가입자 프로파일에 등록한다.
3. 등록 후 최대 90초 이내 인증이 완료된다.

장비 재부팅은 필요하지 않으며, 재부팅 시 동일 PON 포트의 정상 가입자 전체가 단절되므로 수행하지 않는다.

## E-412 인증 타임아웃

E-412는 ONT가 응답하지 않아 인증이 완료되지 않은 경우다.
주된 원인은 광 수신 레벨 저하이며, 수신 레벨이 -27dBm 이하일 때 빈번히 발생한다.
광 커넥터 청소 후 레벨을 재측정하고, 개선되지 않으면 선번장을 기준으로 구간 손실을 점검한다.
